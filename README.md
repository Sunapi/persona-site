# Persona

Статичний сайт-портфоліо на Astro. Каталог перенесено зі старого Bitrix-сайту:

- 447 робіт;
- 9 категорій;
- окремі статичні сторінки проєктів і категорій;
- інтерфейс та URL-структура EN/FI/UK/RU;
- статична пагінація, пошук, сортування й фільтр за рівнем;
- адаптивні галереї з клавіатурним lightbox;
- оптимізовані WebP-галереї без бази даних і серверного runtime.

Основна мова — англійська без префікса. Фінська доступна в `/fi/`,
українська — в `/uk/`, російська — в `/ru/`. Усі чотири локалі містять
повністю перекладені інтерфейс, категорії, назви робіт і артикули.

Переклади зібрані в `src/i18n/`:

- `interface.json` — рядки інтерфейсу, однаковий набір ключів для всіх локалей;
- `categories.json` — назви й описи категорій;
- `project-names.json` — назви всіх 443 унікальних робіт; ключ — оригінальна
  російська назва з `src/data/portfolio.json`, значення — `[en, fi, uk]`
  (для `ru` використовується сам ключ).

Додаючи роботу до каталогу, додайте її назву в `project-names.json` — без
запису решта локалей покаже оригінальну російську назву.

## Локальна розробка

Потрібен Node.js 22.12 або новіший.

```sh
npm install
npm run dev
```

## Перевірка та деплой

```sh
npm run build
npm run preview
npm run deploy
```

Production: [persona.od.ua](https://persona.od.ua)

Cloudflare бере статичні файли з `dist/`. База даних і серверний runtime не використовуються.
