# Persona

Статичний сайт-портфоліо на Astro. Каталог перенесено зі старого Bitrix-сайту:

- 447 робіт;
- 9 категорій;
- окремі статичні сторінки проєктів і категорій;
- інтерфейс та URL-структура EN/FI/UK/RU;
- статична пагінація, пошук, сортування й фільтр за рівнем;
- адаптивні галереї з клавіатурним lightbox;
- оптимізовані WebP-галереї без бази даних і серверного runtime.

Основна мова — англійська без префікса. Фінська доступна в `/fi/`,
українська — в `/uk/`, російська — в `/ru/`. Українська версія містить
повністю локалізований інтерфейс, категорії та назви архівних робіт.
Для робіт без ручного перекладу в інших локалях показується оригінальний
контент із Bitrix-архіву.

## Локальна розробка

Потрібен Node.js 22.12 або новіший.

```sh
npm install
npm run dev
```

## Перевірка та деплой

```sh
npm run build
npm run preview
npm run deploy
```

Production: [persona.od.ua](https://persona.od.ua)

Cloudflare бере статичні файли з `dist/`. База даних і серверний runtime не використовуються.
